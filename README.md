# Unix Text Utilities

Command-line text processing tools written in C, implementing functionality inspired by the Unix `cat` and `grep` utilities.

## What it does

- Reads and displays text files from the terminal.
- Searches text using patterns and regular expressions.
- Supports command-line options for controlling output and matching behavior.

## Engineering focus

C programming, command-line argument parsing, file I/O, string processing, and testing behavior against established Unix utilities.

## Structure

The `src/` directory contains the implementation. Build instructions and executable names should be verified against the included Makefiles.
